## Methodology and data-quality notes

Cost = quantity x benchmark rate, summed over successful calls only. Quantities come from each record's
`params` (characters of narration text, one per image, `target_duration_s` for Wan clips) and from `gpu_min`.
Failed calls are priced at $0.

- 6 record(s) were merged in from `music_runs.jsonl` (notebook logs that were never appended to `runs.jsonl`). Records already present in both are counted once.
- Some GPU records carry no `platform`, so Kaggle and Colab time cannot be told apart. Newer ACE-Step runs record it in `params.platform`; pass `--extra-log colab=PATH` or `kaggle=PATH` to label an older log.
- **Cache hits are never logged** (`cache_hit` is always `false`; the pipeline only logs real model calls). The cache-hit column therefore shows 0, which means 'not recorded', not 'none occurred'.
- **Retries are not logged** for narration, keyframes or shots: `with_retries` records only the final outcome, so 'n/l' appears in the Retries column. Only `ceiling_multilingual` records an `attempts` count.
- `est_cost_usd` is hard-coded to 0.0 by the pipeline, so the out-of-pocket column reflects the free-tier design, not a measured bill.
- 1 GPU record(s) have a `test*` shot id (e.g. `test_merge`) with empty params. They exercise the log-merge path and are not real shot generations, so GPU minutes and Wan latency are **not** representative.
- 9 shot clip(s) came from the FFmpeg Ken Burns fallback and are priced $0 as video.
- Music records for the loudnorm step carry no GPU time; a real ACE-Step run adds `gpu_min` and shows up in the GPU columns.
- 17 failed keyframe call(s) are priced at $0. A commercial API may bill some of them (e.g. 'no usable image' responses), so real list-price spend could be slightly higher.
